# Power Automate Projects

Collection of Microsoft Power Automate cloud flows for business process automation, integrations, and workflow optimization.

## Documented projects

- [SharePoint & Excel Automation](SharePoint-Excel-Automation/README.md): conceptual architecture covering FL01–FL05, Office Scripts, SharePoint libraries, and technical documentation.
- [Service Expiration Alerts](Service-Expiration-Alerts/README.md): tested scheduled reminder flow, English Mermaid diagram, and anonymized workflow reference.

The SharePoint & Excel Automation workflow JSON files are conceptual demonstrations, while the Service Expiration Alerts JSON is an anonymized definition derived from a tested flow. Neither is a complete importable Power Platform solution.
